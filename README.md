# Cloud-Native Portfolio Deployment

A DevOps project demonstrating cloud deployment and CI/CD automation using AWS, Docker, and GitHub Actions.

## Tech Stack

- AWS EC2
- Docker
- GitHub Actions
- Linux (Ubuntu)
- Git & GitHub
- HTML/CSS

## Features

- Dockerized web application
- Hosted on AWS EC2
- Automated deployment using GitHub Actions
- SSH-based deployment pipeline
- Publicly accessible cloud-hosted website

## Architecture

Developer
→ GitHub Repository
→ GitHub Actions
→ AWS EC2
→ Docker Container
→ Live Website

## Skills Demonstrated

- Linux Administration
- Docker Containerization
- AWS Cloud Deployment
- CI/CD Automation
- Git Version Control
- Troubleshooting
